Empresas

Cadastrar uma empresa

Acesse Administração da Empresa → Cadastrar. Cada empresa é independente no sistema — lançamentos, funcionários e relatórios são sempre segregados por empresa.

Grupos econômicos

Empresas podem ser agrupadas em um Grupo Econômico. A empresa principal do grupo é a matriz. O agrupamento é usado para organizar o painel administrativo e futuros relatórios consolidados.

Funcionários

Importação em lote

Para múltiplos funcionários, use Funcionários → Importar. Baixe o modelo (.xlsx), preencha uma linha por funcionário e faça o upload. O sistema valida os dados e apresenta o resultado da importação com detalhes por linha.

Não altere as colunas do modelo. Campos fora do padrão serão ignorados ou causarão erro na importação.

Vínculos Empregatícios

O vínculo conecta um funcionário a uma empresa com período definido (admissão / demissão). Um funcionário pode ter vários vínculos ao longo do tempo — inclusive em empresas diferentes.

Criar um vínculo

Na tela de detalhe do funcionário, clique em Novo Vínculo. Informe:

  • Empresa — empresa à qual o funcionário está vinculado naquele período.
  • Data de admissão — início do contrato.
  • Data de demissão — deixar em branco se o funcionário ainda está ativo.
  • Salário base — usado para calcular a base FGTS nos lançamentos automáticos.
O sistema identifica o vínculo ativo pelo campo data de demissão em branco. Ao desligar um funcionário, preencha a data de demissão no vínculo — não exclua.

Transferência entre empresas

Em Funcionários → Transferir, encerre o vínculo atual e crie um novo para a empresa destino. O histórico de lançamentos anteriores é preservado na empresa de origem.

Lançamentos

Conceitos fundamentais

  • Base FGTS: soma das verbas habituais tributáveis (salário, horas extras, adicionais) sobre as quais incide a alíquota de 8%.
  • Valor FGTS: calculado automaticamente como base_fgts × 8%. Qualquer alteração na base recalcula o valor ao salvar.
  • Competência: mês e ano de referência no formato MM/AAAA. Para 13º salário, use 13/AAAA.
  • Parcela 13º: somente para competência 13. Informe 1 (primeira parcela) ou 2 (segunda parcela).
  • Pago: indica se o depósito foi efetuado. Preencha a data e o valor pago quando confirmar o recolhimento.

Lançamento manual

Acesse Lançamentos → Novo. Preencha empresa, funcionário, competência e base FGTS. O sistema calcula o valor automaticamente.

Use lançamentos manuais para competências específicas, rescisões, ou correção de valores já processados.

Exclusão em massa

Na lista de lançamentos, marque os itens desejados (checkbox) e use Excluir Selecionados. Funciona para exclusão de competências inteiras ou grupos de funcionários.

Geração Automática de Lançamentos

O sistema gera lançamentos para toda a vigência do vínculo de uma só vez. Acesse o detalhe do funcionário e clique em Gerar Lançamentos — ou use Gerar por Vínculo para gerar apenas para um vínculo específico.

Regras de geração

  • Competências geradas: do mês de admissão até o mês atual (ou mês de demissão, se aplicável).
  • Competências que já possuem lançamento para o mesmo funcionário e vínculo são ignoradas — sem duplicatas.
  • A base FGTS é preenchida com o salário base do vínculo. Ajuste manualmente se houver variações (comissões, horas extras).
  • O campo 13/AAAA não é gerado automaticamente — deve ser criado manualmente.

Importação de Arquivo SEFIP.RE

Permite migrar histórico de lançamentos a partir de arquivos SEFIP.RE gerados pelo aplicativo SEFIP da Caixa Econômica Federal (ou qualquer sistema compatível). Acesse SEFIP → Importar SEFIP.RE no menu lateral (/lancamentos/sefip/importar/).

Processo

  1. Selecione a empresa de destino (os lançamentos serão associados a ela).
  2. Faça upload do arquivo .RE ou .TXT no formato SEFIP (360 caracteres por linha, ISO-8859-1).
  3. O sistema lê o registro 00 para identificar a competência (YYYYMM) e os registros 301 para os dados do trabalhador.
  4. Ao final, exibe o resultado: lançamentos criados, ignorados (duplicatas ou PIS não encontrado) e erros por linha.

Campos lidos do registro 301

CampoPosiçãoUso
PIS / NIS32–42Chave para localizar o funcionário no sistema
Nome53–122Exibido nos avisos de PIS não encontrado
Base FGTS167–18115 chars: 13 inteiros + 2 decimais
CompetênciaReg. 00 / 291–296YYYYMM ou YYYY13 → convertido para MM/AAAA
O PIS é a chave de correspondência. Funcionários não encontrados no sistema são sinalados como aviso e ignorados — o lançamento não é criado. Cadastre os funcionários antes de importar.

Conferência de Lançamentos

O módulo de conferência permite revisar, aprovar ou rejeitar lançamentos antes da geração do SEFIP. Funciona como uma camada de validação interna.

Fluxo

  1. Acesse Lançamentos → Conferência e selecione o lançamento a revisar.
  2. Analise os campos — competência, base, valor calculado, dados do funcionário.
  3. Clique em Conferir para aprovar ou Rejeitar para devolver com observação.
  4. Lançamentos rejeitados ficam sinalizados para o responsável corrigir.

Relatórios

Relatório por Competência

Acesse Lançamentos → Relatório. Filtre por empresa, competência e, opcionalmente, funcionário. O relatório exibe:

  • Base FGTS de cada trabalhador
  • Valor calculado (8% sobre a base)
  • Correção pela tabela JAM (juros e atualização monetária)
  • Total atualizado até a data de pagamento informada
O cálculo com JAM só é aplicado quando a data de pagamento é posterior à competência. Para relatórios sem atualização, deixe a data de pagamento no mesmo mês da competência.

Exportações — CSV e PDF

CSV

Exporta os lançamentos filtrados em formato de planilha. Cada linha representa um lançamento com colunas: funcionário, PIS, competência, base FGTS, valor FGTS, correção e total. Compatível com Excel, Google Sheets e sistemas de importação.

PDF — Relatório Profissional

Gera um PDF com layout formatado, pronto para entrega ao cliente. Inclui nome da empresa, competência, lista de funcionários e totais consolidados.

Memória de Cálculo

O download da memória de cálculo exibe o detalhamento mês a mês da atualização de cada lançamento. Inclui:

  • Valor original do depósito
  • Índice JAM aplicado a cada mês
  • Saldo acumulado após cada correção
  • Total final com juros e correção monetária

Útil para auditorias, ações trabalhistas e conferência de saldos com o extrato da Caixa Econômica Federal.

SEFIP.RE

O que é

O SEFIP.RE é o arquivo de transmissão das informações de FGTS e previdência social. Formato fixo: 360 caracteres por linha, codificação ISO-8859-1. Gerado pela plataforma e transmitido via SEFIP/Conectividade Social.

Pré-requisitos

  • O recurso deve estar habilitado para a empresa (solicitação ao administrador da conta).
  • Funcionários com PIS cadastrado e vínculo ativo na competência desejada.
  • Lançamentos registrados para a competência a exportar.

Como gerar

  1. Acesse SEFIP no menu lateral (só aparece quando habilitado).
  2. Selecione empresa, competência (MM/AAAA) e o intervalo de funcionários.
  3. Clique em Gerar. O download do arquivo SEFIP.RE é iniciado automaticamente.

Estrutura do arquivo

RegistroConteúdo
00Cabeçalho do arquivo — identificação
10Dados da empresa (CNPJ, FPAS, CNAE, RAT)
301Dados do trabalhador e base FGTS
40Remunerações variáveis (horas extras, adicionais)
50Descontos (INSS e IR) — gerado somente se houver valor
60Contribuição sindical — gerado somente se houver valor
90Totalizador — contagem real de linhas do arquivo

Calculadora FGTS

Ferramenta pública acessível em /calculadora-fgts/, sem necessidade de login. Permite calcular o FGTS corrigido de um trabalhador informando:

  • Competência de referência
  • Base FGTS (salário bruto)
  • Data de pagamento (para cálculo da correção JAM)

O resultado é exibido na tela. O usuário pode informar um e-mail para receber o relatório premium em PDF com memória de cálculo detalhada.

Indicada para apresentação rápida a clientes ou conferência de valores antes de ações trabalhistas.

Índices JAM

A tabela de índices JAM (Juros e Atualização Monetária) é usada para corrigir o saldo do FGTS de competências passadas até a data de pagamento. Acesse /indices/ para visualizar os índices cadastrados.

Os índices são atualizados mensalmente pela Caixa Econômica Federal. O sistema utiliza os coeficientes acumulados para calcular a correção de forma auditável.

Se um lançamento de competência recente mostrar correção zerada, verifique se o índice daquele mês já foi cadastrado na tabela.
